# Liberu Dark Theme

Dark public/portal theme optimized and tested for `liberu/boilerplate-laravel:^1.0`. Composer package `liberu/theme-dark` installs to `/themes/dark`, inherits all structure from `liberu-base`, and overrides semantic tokens only. Build with `npm run build`; compressed CSS/JS budgets are 80/40 KiB.

It preserves WCAG 2.2 AA focus/contrast, RTL, zoom, reduced motion, forced colors, and server-rendered fallbacks. It contains no third-party scripts or non-original assets. Select another safe theme before Composer uninstall; breaking token or extension-point changes require a major release.
