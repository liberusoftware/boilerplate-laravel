# Liberu Base Theme

Shared Composer presentation package `liberu/theme-base`, installed to `/themes/liberu-base`. It provides the stable semantic-token contract, accessible Blade document layout, skip link, landmarks, responsive primitives, RTL logical properties, light/dark/high-contrast states, reduced motion, and progressive JavaScript hook inherited by public, portal, and admin themes.

It is optimized/tested for `liberu/boilerplate-laravel:^1.0`; compatible hosts may consume its `application.shell`, `identity.auth`, and `foundation.account` extension points. Build with the host Vite pipeline. Budgets are 60 KiB compressed CSS and 20 KiB compressed JS. There are no third-party scripts, fonts, images, or licensing obligations. Stable tokens, layouts, slots, and asset entries follow semantic versioning.
