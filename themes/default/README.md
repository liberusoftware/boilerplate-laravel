# Liberu Default Theme

Neutral public/portal presentation optimized and tested for `liberu/boilerplate-laravel:^1.0`. Composer package `liberu/theme-default` installs to `/themes/default`, inherits `liberu-base`, and supports the application shell, authentication, and account extension points. Build with `npm run build`; its CSS budget is 80 KiB compressed and JavaScript budget is 40 KiB compressed.

It supports light/dark system modes, responsive layouts, RTL logical properties, WCAG 2.2 AA focus/contrast targets, reduced motion, forced colors, CSP-safe external assets, and graceful server-rendered operation without optional JavaScript. No third-party media or licensed non-original assets are included. Update through Composer and commit the lockfile plus tracked theme diff; uninstall only after selecting another safe theme.
